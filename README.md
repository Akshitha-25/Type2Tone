# Type2Tone 🎵

Type2Tone is a web-based application that converts text into different tones, making communication more expressive and engaging. The project is built using **HTML**, **CSS**, and **JavaScript**, providing a simple, responsive, and user-friendly interface.

## 📌 Features

- 🏠 **Home Page** – Introduction to the project and navigation.
- ℹ️ **About Us Page** – Information about the project and its purpose.
- 📞 **Contact Page** – Allows users to get in touch or provide feedback.
- ✨ **Main Page** – Core functionality where users can enter text and transform it into different tones.
- 📱 Responsive design for desktop and mobile devices.
- 🎨 Clean and modern user interface.

## 🛠️ Technologies Used

- **HTML5** – Structure of the website.
- **CSS3** – Styling and responsive design.
- **JavaScript (ES6)** – Interactive functionality and tone conversion logic.
- **Visual Studio Code** – Development environment.

## 🚀 How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/your-username/Type2Tone.git
```

2. Open the project folder in **Visual Studio Code**.

3. Open `index.html` in your browser.

**OR**

- Install the **Live Server** extension in VS Code.
- Right-click on `index.html`.
- Select **Open with Live Server**.

## 📖 Usage

1. Open the Home Page.
2. Navigate to the **Main Page**.
3. Enter the text you want to modify.
4. Select or generate the desired tone.
5. Copy or use the generated text as needed.
